# 🧠 Mental Diagnostic App

**Mental Diagnostic App** — это настольное приложение, разработанное на Python с использованием фреймворка [Flet](https://flet.dev/), предназначенное для **первичной диагностики психических расстройств и психологических проблем**.  

Проект ориентирован на специалистов и пользователей, желающих оперативно провести базовый скрининг психического состояния с помощью набора валидированных тестов.

---

## ⚙️ Основной функционал

- 🔐 **Авторизация** — защищённый вход для ограниченного доступа к базе.
- 🔍 **Поиск пациентов** — быстрый доступ к истории и данным пациентов.
- ➕ **Добавление новых пациентов** — возможность создавать записи с ключевыми данными.
- 🧾 **Шифрование базы** — конфиденциальность данных через `Fernet`-шифрование.
- 📚 **Правила и инструкции** — встроенный справочный раздел.
- 📈 **Планируемое расширение** — интеграция широкого спектра психодиагностических тестов (депрессия, тревожность, ПТСР, зависимости и др).
